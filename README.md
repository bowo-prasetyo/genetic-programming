# genetic-programming → EquVolve

This project is now **EquVolve**: [github.com/bowo-prasetyo/equvolve](https://github.com/bowo-prasetyo/equvolve), live at [bowo-prasetyo.github.io/equvolve](https://bowo-prasetyo.github.io/equvolve/).

This repository only keeps the old address working. Its GitHub Pages site forwards every old link to the same place on the new site:

| Old address | Goes to |
| --- | --- |
| `bowo-prasetyo.github.io/genetic-programming/` | `bowo-prasetyo.github.io/equvolve/` |
| `…/genetic-programming/#/?run=…` (share links) | `…/equvolve/#/?run=…` |
| `…/genetic-programming/#/about` | `…/equvolve/#/about` |
| `…/genetic-programming/anything/else` | `…/equvolve/anything/else` |

`index.html` does the forwarding; `404.html` is a copy of it, so that deeper paths are forwarded too. Visitors with JavaScript turned off are sent to the start page.

Please open issues and pull requests on [EquVolve](https://github.com/bowo-prasetyo/equvolve).
